# Project Context: HomeHarmony (FamilyLedger)

**HomeHarmony** (`FamilyLedger` internal product/architecture name) is a multi-tenant, family-shared financial hub and modular life platform built on AWS Serverless (API Gateway, AWS Lambda, EventBridge, Cognito), Rust (Clean Architecture / DDD hexagonal workspace), and Amazon Aurora DSQL (with PostgreSQL test compatibility). It spans two sibling Git repositories under `home-harmony/`: `documentation/` (central architecture, domain models, ADRs, declarative behavior specifications, and cross-repo AI governance) and `backend/` (pure `domain/`, `infrastructure/`, `api/`, `lambdas/*`, and `migrations/`). Domain integrity relies on float-free `rust_decimal::Decimal` money, strongly-typed `nutype`/UUID v4/v7 value objects, verified `X-Family-Id` multi-family isolation, immutable append-only ledger transactions corrected via reversals, and a Spec-Driven Development workflow where humans own `Approved` specifications and `Accepted` ADRs while AI assists with research, drafting, test generation, and implementation.
