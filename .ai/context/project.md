# Project Context: HomeHarmony (FamilyLedger)

**HomeHarmony** (`FamilyLedger` internal product/architecture name) is a multi-tenant, family-shared financial hub and modular life platform built on AWS Serverless (API Gateway, AWS Lambda, EventBridge, Cognito, S3, CloudFront), Rust (Clean Architecture / DDD hexagonal workspace), Amazon Aurora DSQL (with PostgreSQL test compatibility), and Angular 22 (`spartan/ui` 1.0 + Tailwind CSS v4 + OKLCH themes). It spans three sibling Git repositories under `home-harmony/` (`ADR-0004`): `documentation/` (central architecture, domain models, ADRs, research notes, and cross-repo AI governance), `backend/` (pure `domain/`, `infrastructure/`, `api/`, `lambdas/*`, `migrations/`, and self-contained declarative behavior specifications in `backend/specs/`), and `frontend-web/` (zoneless signal-driven Angular SPA organized into progressive DDD bounded-context slices with suffixless role folders and three-layer semantic styling). Domain integrity relies on float-free `rust_decimal::Decimal` money, strongly-typed `nutype`/UUID v4/v7 value objects, verified `IdToken` + `X-Family-Id` multi-family isolation, localized RFC 9457 `error.code` mapping, immutable append-only ledger transactions corrected via reversals, and a Spec-Driven Development workflow where humans own `Approved` specifications and `Accepted` ADRs.
